# Back Two EPITA Website

This website was developed to present Back Two EPITA, a cooperative puzzle adventure created as part of a group project at EPITA.

It introduces the game, explains its concept and gameplay, presents the development team and provides access to the game and project documentation.

## Features

- Homepage introducing the game and its concept
- Dedicated page explaining the gameplay and story
- Team presentation with individual profiles and roles
- Download link for the game
- Access to the installation guide and project reports
- Navigation between the different pages
- Custom interface with animations and interactive elements

## Technologies

- **Next.js 15** for the web application
- **React** for the interface components
- **TypeScript** for development
- **Tailwind CSS** for styling

## Installation and Usage

The project requires Node.js and npm.

Clone the repository and install the dependencies:

```bash
git clone https://github.com/Flo42n/BackTwoEpita-website.git
cd BackTwoEpita-website
npm install
```

Start the development server:

```bash
npm run dev
```

Then open `http://localhost:3000` in your browser.

To create a production build:

```bash
npm run build
```

## Project Structure

- `app/`: website pages and application routes
- `app/components/`: reusable interface components
- `app/about_the_game/`: game presentation and downloads
- `app/our_team/`: development team presentation
- `public/`: images, logos and project documentation
- `lib/` and `utils/`: utility functions

## About the Project

The website was developed alongside Back Two EPITA to provide a dedicated space for presenting the game and the team behind it.

It brings together the game's story, features, downloadable resources and team information in a single interface.

The website is part of a larger group project combining game development with Unity and C# and web development with React and Next.js.
